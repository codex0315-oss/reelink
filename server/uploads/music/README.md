# Reel background music

Drop `.mp3` files here and name them to match the `music` field in
`src/modules/reels/reel-templates.ts`:

| File            | Used by   | Suits                              |
|-----------------|-----------|------------------------------------|
| `classic.mp3`   | Classic   | warm, unhurried, acoustic          |
| `luxury.mp3`    | Luxury    | slow, cinematic, piano or strings  |
| `quicktour.mp3` | Quicktour | upbeat, percussive, quick cuts     |
| `bold.mp3`      | Bold      | modern, confident, light beat      |

A missing file is not an error — that reel simply renders without music, exactly as
it does today. Add them one at a time and re-render to compare.

## Licensing — read before adding anything

These tracks are published on Facebook and Instagram under an agent's name, so the
licence has to permit **commercial use**. Free sources that do:

- **Pixabay Music** — pixabay.com/music (no attribution required)
- **YouTube Audio Library** — studio.youtube.com (check the per-track attribution flag)
- **Incompetech** (Kevin MacLeod) — incompetech.com (CC-BY, attribution required)
- **Free Music Archive** — freemusicarchive.org (licence varies per track, check each)

Avoid anything from a streaming service or a "free download" site that does not state
a licence. A copyright claim on an agent's page is a worse outcome than a silent reel.

Keep each track at least as long as the longest reel (~30s) so it never runs out, and
prefer something that starts immediately rather than fading in over four seconds.
